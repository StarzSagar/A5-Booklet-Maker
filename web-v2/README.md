# STARz Booklet Maker Web App

A browser-based version of STARz Booklet Maker. Upload a PDF, choose the pages
to include, preview them, and download an imposed booklet PDF.

## Run locally

Requires Python 3.10 or newer.

From this folder, install the dependencies and start the server:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app:app --reload
```

Open <http://127.0.0.1:8000> in your browser. To allow other devices on your
local network to connect, start Uvicorn with `--host 0.0.0.0` and use this
computer's local IP address. Authentication is disabled by default for local
development. Do not expose a server without authentication to the public
internet.

## Deploy on Render

The project includes a Render Blueprint in the repository root. It deploys
only `web_app/`, installs its requirements, and enables browser
Basic Authentication with a password generated by Render.

1. Create a **private GitHub repository** and upload the project files. Include
   `render.yaml`, `.gitignore`, and `web_app/`. Do not upload `.venv/`, `build/`,
   or `dist/`; they are excluded by `.gitignore`.
2. Sign in at <https://render.com>, select **New** → **Blueprint**, and connect
   your GitHub account and repository.
3. Review the `starz-booklet-maker` web service and select **Apply**.
4. When deployment finishes, open the service's **Environment** page and copy
   the generated `APP_PASSWORD`. The username is `booklet-user`.
5. Open the service's `onrender.com` URL and enter those credentials when your
   browser prompts you to sign in. Render provides HTTPS for the service URL.

Keep the generated password private. You can change it in the Render
Environment settings; save the change and redeploy. Uploaded PDFs are
temporary: they are deleted when the service restarts or after one hour. Free
Render web services can spin down while idle, so the first request after
inactivity may take longer.

## Use

1. Choose a PDF (up to 50 MB and 1,000 pages). All pages are selected initially.
2. Select or clear individual page cards, or use the selection and page-range
   controls.
3. Choose a light, dark, or system theme, select an accent color, and adjust
   the number of page previews per row (2 columns on mobile) and thumbnail
   quality.
4. Choose **Generate booklet** to download the print-ready PDF.

The output uses A4 landscape sheets, with two source-page areas on each side.
Blank pages are inserted as needed so the selected pages can be folded into a
booklet. Each uploaded PDF is held temporarily on the server and removed when
the server stops or the upload expires after one hour.

## Project files

- `app.py` — FastAPI server and PDF upload, preview, and generation endpoints.
- `booklet_engine.py` — booklet page-imposition logic.
- `static/` — browser interface, styles, and client-side selection controls.
